#### 🚀 Featured project

**[Olist Analytics: dbt on Databricks](https://github.com/thaisdahack/olist-analytics-dbt)**  
End-to-end analytics engineering project using dbt Core on Databricks Delta 
Lake. Star schema modeling of Brazilian e-commerce data (~100k orders) to 
answer: *how does delivery performance affect customer satisfaction?* 
The finding: late deliveries drop average review scores by 40%.
